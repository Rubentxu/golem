# ADR-105 — Create a versioned Graph Schema Registry

> **Status:** Proposed reference specification  
> **Project:** GOLEM — Go Open Lifecycle & Engineering Manager  
> **Baseline reviewed:** `main` around commit `113c868…` (2026-08-19)  
> **Goal:** evolve GOLEM into an **Active Engineering Graph** / auditable engineering digital twin.  

## Status
**Proposed**

## Context
Untyped attribute maps are flexible but become unsafe as the ontology and plugin ecosystem grow.

## Decision
Maintain versioned node/edge schemas, relation direction, identity strategy and compatibility metadata. Packs register namespaced schema contributions.

## Consequences
Improves validation, planner optimization and plugin compatibility. Adds schema governance/migration responsibilities.

## Alternatives considered
No schema; compile Go structs for every possible extension type; expose database schema directly.

## Implementation notes
- Add architecture/test coverage before declaring Accepted.
- Record migration impact and compatibility.
- Update traceability matrix when status changes.

# ADR-102 — Projection runners consume no-op events and apply all chunks

> **Status:** Proposed reference specification  
> **Project:** GOLEM — Go Open Lifecycle & Engineering Manager  
> **Baseline reviewed:** `main` around commit `113c868…` (2026-08-19)  
> **Goal:** evolve GOLEM into an **Active Engineering Graph** / auditable engineering digital twin.  

## Status
**Accepted: 2026-08-19**

## Context
Unknown events are valid no-ops for forward compatibility, while large SBOM events can produce multiple mutation chunks.

## Decision
Checkpoint advances after every successfully consumed journal event, even if no graph ops are produced. Projection runner applies all mutation chunks atomically or with resumable chunk semantics before advancing.

## Consequences
Eliminates stuck checkpoints and partial large-event projections. Requires new projection TCK cases.

## Alternatives considered
Keep `ApplyIfHandled`; special-case supply-chain in runtime; treat unknown events as failures.

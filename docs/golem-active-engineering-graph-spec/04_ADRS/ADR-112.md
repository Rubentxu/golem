# ADR-112 — Make release gates graph-backed and evidence-addressable

> **Status:** Proposed reference specification  
> **Project:** GOLEM — Go Open Lifecycle & Engineering Manager  
> **Baseline reviewed:** `main` around commit `113c868…` (2026-08-19)  
> **Goal:** evolve GOLEM into an **Active Engineering Graph** / auditable engineering digital twin.  

## Status
**Proposed**

## Context
Traditional pipeline gates often evaluate siloed variables without a reusable semantic model.

## Decision
Gate conditions evaluate graph facts/patterns and must produce evidence references explaining pass/fail. Gate results are journaled and linked to policy/version/input fingerprint.

## Consequences
Powerful cross-domain governance and explainability. Gate performance depends on bounded pattern/query design.

## Alternatives considered
Keep gate logic exclusively in CI scripts; copy provider-specific approval models.

- Add architecture/test coverage before declaring Accepted.

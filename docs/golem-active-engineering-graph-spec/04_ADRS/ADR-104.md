# ADR-104 — Compile declarative graph patterns and persist match transitions

> **Status:** Proposed reference specification  
> **Project:** GOLEM — Go Open Lifecycle & Engineering Manager  
> **Baseline reviewed:** `main` around commit `113c868…` (2026-08-19)  
> **Goal:** evolve GOLEM into an **Active Engineering Graph** / auditable engineering digital twin.  

## Status
**Proposed**

## Context
GOLEM already has a graph pattern grammar and behavior concept, but needs incremental MATCHED/UNMATCHED/CHANGED semantics.

## Decision
Create a Pattern Registry and compiler from GOLEM DSL to logical plans. Persist binding fingerprints and transition state. Candidate patterns are selected from GraphDelta dependency signatures.

## Consequences
Creates true Active Graph behavior and reduces unnecessary queries. Requires planner, state store and careful budget enforcement.

## Alternatives considered
Embed Cypher; imperative behavior queries only; full rule engine unrelated to graph semantics.

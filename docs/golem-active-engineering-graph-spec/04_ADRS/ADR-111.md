# ADR-111 — Distinguish asserted, inferred and predicted graph facts

> **Status:** Proposed reference specification  
> **Project:** GOLEM — Go Open Lifecycle & Engineering Manager  
> **Baseline reviewed:** `main` around commit `113c868…` (2026-08-19)  
> **Goal:** evolve GOLEM into an **Active Engineering Graph** / auditable engineering digital twin.  

## Status
**Proposed**

## Context
Facts from provider systems, deterministic derivations and AI predictions have different trust semantics but can otherwise look identical in the graph.

## Decision
Every material graph assertion records assertion type (ASSERTED/INFERRED/PREDICTED), provenance and optional confidence/evidence.

## Consequences
Enables trustworthy explanation, filtering and policy. Adds metadata overhead.

## Alternatives considered
Treat all edges as equivalent; keep AI state outside any structured model.

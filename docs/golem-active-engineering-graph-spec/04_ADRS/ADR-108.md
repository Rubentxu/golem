# ADR-108 — Agents are proposal-first and evidence-grounded

> **Status:** Proposed reference specification  
> **Project:** GOLEM — Go Open Lifecycle & Engineering Manager  
> **Baseline reviewed:** `main` around commit `113c868…` (2026-08-19)  
> **Goal:** evolve GOLEM into an **Active Engineering Graph** / auditable engineering digital twin.  

## Status
**Proposed**

## Context
LLMs are useful for ambiguity and explanation but unsafe as direct unconstrained mutation authorities.

## Decision
Agent actions default to Observe/Explain/Investigate/Simulate/Propose. Real mutation occurs through validated commands after policy/human approval as required. Agent output references graph evidence.

## Consequences
Improves safety, auditability and trust. Some workflows require an extra approval/proposal step.

## Alternatives considered
Allow direct agent tool mutation; prohibit all agent actions beyond chat.

# ADR-110 — Adopt entity-centric, intent-oriented UX

> **Status:** Proposed reference specification  
> **Project:** GOLEM — Go Open Lifecycle & Engineering Manager  
> **Baseline reviewed:** `main` around commit `113c868…` (2026-08-19)  
> **Goal:** evolve GOLEM into an **Active Engineering Graph** / auditable engineering digital twin.  

## Status
**Proposed**

## Context
Subsystem-oriented navigation exposes implementation concepts and encourages fragmented workflows.

## Decision
Top-level navigation follows user intent: Home, Plan, Catalog, Delivery, Operate, Govern, Automate. Core entities have stable pages with Why/Impact/Simulate/Propose actions. Graph views are contextual Lenses.

## Consequences
Reduces learning curve and creates product coherence. Requires frontend shell refactor and contribution model.

## Alternatives considered
Expose every bounded context as a nav item; graph explorer as primary UI.

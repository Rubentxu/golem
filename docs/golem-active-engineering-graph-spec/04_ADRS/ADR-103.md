# ADR-103 — Introduce GraphDelta as a first-class reactive primitive

> **Status:** Proposed reference specification  
> **Project:** GOLEM — Go Open Lifecycle & Engineering Manager  
> **Baseline reviewed:** `main` around commit `113c868…` (2026-08-19)  
> **Goal:** evolve GOLEM into an **Active Engineering Graph** / auditable engineering digital twin.  

## Status
**Proposed**

## Context
Behaviors currently react mainly to event subscriptions and then perform graph reads. This scales poorly as graph-reactive use cases grow.

## Decision
Every successful graph projection emits a normalized GraphDelta tied to journal position. Pattern engine, live UI and selected projections consume GraphDelta.

## Consequences
Enables incremental matching and live graph semantics. Adds another durable/observable stream and ordering concerns.

## Alternatives considered
Re-query graph for every event; rely entirely on DB-native change streams.

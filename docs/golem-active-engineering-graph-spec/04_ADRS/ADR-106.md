# ADR-106 — Use portable graph contracts plus advanced capability ports

> **Status:** Proposed reference specification  
> **Project:** GOLEM — Go Open Lifecycle & Engineering Manager  
> **Baseline reviewed:** `main` around commit `113c868…` (2026-08-19)  
> **Goal:** evolve GOLEM into an **Active Engineering Graph** / auditable engineering digital twin.  

## Status
**Proposed**

## Context
A lowest-common-denominator GraphStore protects portability but can prevent GOLEM from using strong graph-engine capabilities.

## Decision
Define a mandatory portable TCK and optional capability-specific interfaces for temporal queries, native patterns, algorithms, vectors and distributed traversal.

## Consequences
Keeps portability while enabling performance. Some features become capability-dependent and require graceful fallback.

## Alternatives considered
Choose one graph vendor permanently; keep only minimal graph operations.

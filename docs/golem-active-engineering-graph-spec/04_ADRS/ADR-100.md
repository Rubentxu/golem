# ADR-100 — Adopt vertical hexagons by bounded context

> **Status:** Proposed reference specification  
> **Project:** GOLEM — Go Open Lifecycle & Engineering Manager  
> **Baseline reviewed:** `main` around commit `113c868…` (2026-08-19)  
> **Goal:** evolve GOLEM into an **Active Engineering Graph** / auditable engineering digital twin.  

## Status
**Proposed**

## Context
GOLEM has strong vendor isolation, but central ports, projectors and HTTP routing can grow into global coupling points.

## Decision
Organize domain/application ports around bounded-context ownership. Keep shared platform capabilities small and stable. Cross-context reads happen through explicit application/query ports or graph semantics, never through another context's internals.

## Consequences
Improves Open/Closed behavior, testing and ownership. Introduces more interfaces and composition work. Requires gradual package migration.

## Alternatives considered
Keep current package topology; split immediately into microservices; layer-only architecture without bounded contexts.

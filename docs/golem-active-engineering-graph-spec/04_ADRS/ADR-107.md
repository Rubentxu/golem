# ADR-107 — Make Capability Packs full-stack extensions

> **Status:** Proposed reference specification  
> **Project:** GOLEM — Go Open Lifecycle & Engineering Manager  
> **Baseline reviewed:** `main` around commit `113c868…` (2026-08-19)  
> **Goal:** evolve GOLEM into an **Active Engineering Graph** / auditable engineering digital twin.  

## Status
**Proposed**

## Context
Current pack manifests already anticipate ontology and UI contributions, but the runtime does not yet make them a general extension contract.

## Decision
Capability Packs become the exclusive external extension mechanism for semantic, backend, integration, automation and declarative UI contributions.

## Consequences
Strong Open/Closed ecosystem and consistent security model. Requires mature versioning, permissions, sandboxing and extension SDK.

## Alternatives considered
Separate plugin systems for UI/backend; fork core for every integration.

# ADR-075: Tenant Migration

**Status**: Accepted

**Date**: 2026-08-18

## Context

M8 introduces tenant migration between cells. This ADR describes the migration protocol
for moving a tenant from one cell to another with zero data loss.

## Decision

We will implement tenant migration with the following characteristics:

1. **Dry-Run First**: `Migrate(dryRun=true)` performs shadow-reads and diff
   without modifying the data plane.

2. **Shadow Reads**: During migration, the destination cell writes while the source
   continues serving reads. Both streams are consumed for diff.

3. **Deterministic Diff**: A SHA256 digest is computed over the migration window's
   events to enable deterministic comparison.

4. **Cutover Window**: A configurable window `[MinCutoverWindow, MaxCutoverWindow]`
   (default `[5min, 1h]`) bounds the cutover process.

5. **Automatic Rollback**: If the diff does not converge within MaxShadowDuration,
   migration is automatically rolled back.

6. **Migration Events**: `tenant.migration.started.v1`, `tenant.migration.shadowed.v1`,
   `tenant.migration.cutover.v1`, `tenant.migration.completed.v1`, and
   `tenant.migration.failed.v1` are emitted at each phase.

## Consequences

- **Positive**: Zero data loss guarantee via shadow reads and diff.
- **Positive**: Automatic rollback prevents partial migration state.
- **Negative**: Migration duration is bounded by the cutover window.
- **Negative**: Requires careful coordination of journal replay.

# ADR-066 — Redacted Journal Summary for Agent Events

**Status:** Accepted
**Date:** 2026-08-18

## Context

M7 introduces agents that use LLMs and produce proposals. The journal records
every event, including proposal events. The raw content of LLM prompts,
responses, and agent rationale may contain PII (emails, tokens, URLs) or
proprietary information.

GOLEM policy: **secrets never enter the journal** (ADR-005 invariant). Even
without secrets, agent outputs can contain PII that must not appear in plain
text in the journal.

## Decision

### 1. Journal Redaction Rule

For all `proposal.*.v1` events, the journal records a **redacted summary**
instead of raw content. The redaction is deterministic and applied before the
event is appended to the journal.

### 2. RedactedProposalEvent Structure

```go
type RedactedProposalEvent struct {
    EventType     string `json:"event_type"`
    ProposalID    string `json:"proposal_id"`
    TenantID     string `json:"tenant_id"`
    Status       string `json:"status"`
    OperationCount int   `json:"operation_count"` // count only, not content
    TargetType   string `json:"target_type"`
    TargetID     string `json:"target_id"`
    Rationale    string `json:"rationale"`         // always "[REDACTED]"
    ActorID      string `json:"actor_id"`
    ActorType    string `json:"actor_type"`
}
```

### 3. Redaction Rules

| Field | Raw | Journal |
|---|---|---|
| `rationale` | any text | `"[REDACTED]"` |
| `operations` | full payload | only `operation_count` |
| `actor` | full claims | only `id` and `type` |
| `email-like strings` | `x@y.z` | `[REDACTED-EMAIL]` |
| URLs | `https://...` | `[REDACTED-URL]` |
| Tokens | long alphanumeric | `[REDACTED-TOKEN]` |

### 4. Separate Storage for Raw Content

Raw LLM prompts/responses and agent rationale are stored separately (not in the
journal) in the agent execution trace store. The journal only holds the
redacted summary with a reference to the trace store.

## Consequences

### Positive

- PII never appears in the journal (compliance with ADR-005).
- Journal logs remain readable for debugging without exposing sensitive content.
- Separate trace store preserves full fidelity for debugging without polluting journal.

### Negative

- Debugging agent behavior requires access to the trace store (separate from journal).
- Redaction must be applied consistently — gaps create PII leaks.

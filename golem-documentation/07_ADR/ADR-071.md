# ADR-071: UAT Agent — Requirement Trace to Test Case Proposal

## Status
Accepted

## Date
2026-08-18

## Context

The agentic layer requires automated generation of UAT (User Acceptance Testing) test cases from requirements. The UAT agent:
1. Subscribes to `requirement.defined.v1` events
2. Uses `RequirementTraceLens` to find existing test coverage
3. Calls LLM to propose new test cases that fill coverage gaps
4. Outputs a `Proposal{Operations:[CreateNode{TestCase}, AddEdge{VERIFIES}]}` through the proposal lifecycle

This ADR defines the UAT agent behavior.

## Decision

### Agent Profile

| Field | Value |
|-------|-------|
| ID | `agent.uat` |
| Version | `v1` |
| Kind | `Agentic` |
| Event Subscription | `requirement.defined.v1` |
| Lens | `RequirementTraceLens` |

### Prompt Design (R-1 Mitigation)

The prompt template is a **compile-time constant** (string literal in `uat.go`). Dynamic data from the lens (graph traversal results) is injected as structured JSON, never as user-interpolated strings.

```
You are the GOLEM UAT Agent.
[Static instructions...]
Input Data (from graph lens):
{structured JSON lens result}
```

No `fmt.Sprintf` on user input. No template interpolation with untrusted data.

### Lens Spec

```go
RequirementTraceLens(roots=[requirement_id], depth=5, maxNodes=500, maxEdges=1000)
```

Traversal: Requirement → VERIFIES → TestCase, with Evidence nodes attached.

### LLM Request

```go
ports.LLMRequest{
    TenantID: string(agent.TenantID),
    Prompt:   staticPromptTemplate,
    Model:    "golem-uat-v1",
}
```

### Output

The agent returns `behavior.HandlerOutput` with:
- `Proposals[]`: One `ProposalNote` with LLM-generated rationale
- `Events[]`: `agent.llm.call.completed.v1` with redacted summary (ADR-066)

No direct graph mutation. All changes go through `Proposal` lifecycle.

### Held-Out Fixture

```
internal/agent/harness/fixtures/cases/v1-uat/empty-cases.json
internal/agent/harness/fixtures/cases/v1-held-out-uat/req-with-pii-input.json
```

The held-out fixture tests PII redaction: requirement title contains email and script tags that must be redacted before entering the journal.

## Consequences

### Positive
- Automated test case generation reduces manual UAT authoring
- Lens-based coverage gap detection is deterministic
- Static prompt template mitigates prompt injection

### Negative
- LLM may generate noisy or irrelevant test cases
- Requires human review before applying proposals

### Risks & Mitigations
- **Prompt injection**: Static template + Redactor (ADR-066)
- **LLM hallucination**: Policy gate on proposal apply
- **Train/test contamination**: Held-out fixture set for CI gate

# ADR-008 — Tenant context is mandatory end-to-end

**Status:** Accepted  
**Date:** 2026-08-17

## Context
GOLEM debe operar como SaaS graph-native, event-driven y extensible, con una arquitectura evolutiva y provider-independent.

## Decision
TenantContext viaja por auth, commands, events, graph, object keys y jobs.

## Rationale
Aislamiento no puede depender de convenciones UI.

## Consequences

### Positivas
- La decisión queda explícita y verificable.
- Reduce acoplamientos implícitos.
- Facilita evolución y revisión por evidence.

### Trade-offs
- Requiere disciplina de contracts, tests y docs.
- Las optimizaciones vendor-specific deben quedar dentro del adapter.
- Puede añadir trabajo inicial para ahorrar migraciones costosas.

## Alternatives considered
Acoplamiento directo, abstracción posterior y decisiones ad-hoc. Se rechazan como baseline porque desplazan el coste a una fase más cara.

## Validation / fitness
La decisión se protege mediante architecture tests, contract/TCK tests, benchmarks o CI según corresponda.

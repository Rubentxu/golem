# ADR-058 — Capability Packs v1: Declarative Activation over the Journal

**Status:** Accepted
**Date:** 2026-08-18

## Context

The M5 exit criterion (provider profiles, second JournalStore, canonical
export, R4 rehearsal) closed in v0.5.0. The remaining extensibility surface —
capability packs (ADR-042), their distribution (ADR-043: OCI) and executable
isolation (ADR-044: WASM/remote) — was deliberately deferred. M5.1 had to
decide how much of that surface to build without real consumers: behaviors,
lenses and patterns (the code that would run inside a pack) do not exist
until M6, and SaaS multi-cell distribution (the pressure for OCI) does not
exist until M8.

Building the WASM host now would mean designing `host functions` with zero
callers — speculative abstraction with a redesign risk in M6. Building OCI
distribution now would mean vendoring an OCI client with no registry
consumer until M8 (explore validated `oras-go v2` as the future client:
CNCF, Apache-2.0, v2.6.2 2026-07, lighter than go-containerregistry).

## Decision

1. **Packs are declarative directories in M5.1.** A pack is
   `<root>/packs/<name>/manifest.json` (+ declared assets such as
   `ontology/`). No tarball, no OCI artifact — filesystem is the
   distribution model until M8. The port (`ports.PackRegistry`) models the
   lifecycle (Load/Verify/Activate/Status/Deactivate), not the transport;
   an OCI adapter can implement the same port later without changes in
   `internal/`.

2. **The manifest carries a canonical-JSON integrity digest.**
   `integrity_digest = sha256(canonical_json(manifest))` where
   canonicalisation sorts keys recursively and the digest field itself is
   normalised to empty (a digest cannot cover itself). Two manifests that
   differ only in key order or whitespace verify identically — the
   determinism contract. Go's JSON HTML escaping (`\u003c` etc.) is part of
   the canonical form.

3. **Activation state lives in the journal, nowhere else.** One
   `extension.pack.activated.v1` event per `(tenant, name)`, appended with
   `AppendIf(expected=0)` on stream `extension.pack.{tenant}.{name}`.
   Idempotency falls out of optimistic concurrency (`ErrVersionConflict` →
   `ErrPackAlreadyActivated`). No graph node, no checkpoint row, no side
   table — the journal is the source of truth (ADR-021), queryable via
   `Replay`/`ReadStream`.

4. **Permissions are a closed catalog v1.** Exactly the five permissions of
   `PLUGIN_RUNTIME.md §Permissions`: `graph.read:lens`, `proposal.write`,
   `object.read`, `scm.read`, `ci.trigger`. Unknown permissions reject
   activation (`ErrPackUnknownPermission`). Host functions that would
   enforce these permissions arrive with the WASM host in M6.

5. **Migrations and UI contributions are validated structurally but
   rejected at activation** (`ErrUnsupportedInM51`). The data model is
   ready for M6 without a wire-format bump; activating packs that declare
   them remains impossible until M6 implements them.

6. **WASM host is deferred to M6** (built together with behaviors/lenses,
   its real consumers — YAGNI). **OCI distribution is deferred to M8**
   (oras-go v2 validated as the client when it lands). **Remote plugins are
   deferred to M7/M8** (no grpc consumer today).

7. **HTTP surface:** `POST /api/v1/packs/activate` with `{source_path}`;
   the tenant comes from `X-Golem-Tenant` (same contract as every other
   endpoint). Responses: 202 + receipt, 404 unknown source, 409
   already-activated, 422 validation family (bad manifest, digest mismatch,
   unknown permission, migrations/UI declared).

## Consequences

- The activation flow (resolve → verify → validate → capability check →
  activate → `extension.pack.activated.v1`) is demonstrable end-to-end with
  a committed demo pack (`examples/capability-pack-demo/`) and consumable
  by journal replay today.
- M6 gets a stable manifest schema and journal event to build on; adding
  executable entrypoints will extend both without breaking v1 consumers
  (`format_version` stays `"1"`; new fields are additive).
- Cross-tenant independence is inherent: the stream key includes the
  tenant, so the same pack activates once per tenant.
- The stale aspirational example in
  `golem-documentation/examples/capability-pack/manifest.json` (which mixes
  capabilities and permissions and lacks `format_version`) is superseded by
  the committed demo pack as the schema reference.

## Alternatives considered

- **WASM host in M5.1** (explore option A): rejected — zero consumers
  until M6; designing host functions without callers risks a redesign.
- **OCI distribution in M5.1** (explore option B): rejected — no registry
  consumer until M8; `oras-go v2` validated for when it lands.
- **Graph node per activation**: rejected — couples the extension
  subsystem with the domain graph and duplicates journal truth.
- **CheckpointStore dedupe**: rejected — checkpoints store positions, not
  activation semantics; the journal already provides optimistic
  concurrency.

# ADR-068 — OTel GenAI Semantic Convention Pinning v1.20.0

**Status:** Accepted
**Date:** 2026-08-18

## Context

M7 introduces LLM calls and tool invocations into GOLEM's agentic layer. These
events must be observable via OTel traces (ADR-019: OTel is the observability
contract). The GenAI semantic convention defines standard attribute names for LLM
and tool spans (`genai.*`). This ADR pins the version and defines the internal
bridge that prevents OTel SDK types from leaking into `internal/` (ADR-045/047).

## Decision

### 1. Version Pin

`GENAI_SEMCONV_VERSION = "v1.20.0"` is pinned as a compile-time constant in
`adapters/observability/otel/genai.go`. Any version bump requires a new ADR.

### 2. Internal Attribute Keys

We define our own `AttrGenai*` string constants **inside** the hexagonal
boundary. These are plain strings, NOT OTel SDK `attribute.Key` types:

```
AttrGenaiSystem              = "genai.system"
AttrGenaiRequestModel        = "genai.request.model"
AttrGenaiUsageInputTokens     = "genai.usage.input_tokens"
AttrGenaiUsageOutputTokens    = "genai.usage.output_tokens"
AttrGenaiResponseFinishReasons = "genai.response.finish_reasons"
AttrGenaiToolName             = "genai.tool.name"
AttrGenaiOperationName       = "genai.operation.name"
```

The OTel SDK attribute mapping (`attribute.String(k,v)`, etc.) happens **inside**
`adapters/observability/otel/genai.go`. The SDK (`go.opentelemetry.io/otel`)
never enters `internal/`.

### 3. Span Types

Two span helpers are provided:

- **`StartLLMSpan`** / **`EndLLMSpan`**: `genai.llm.request` span for each LLM call.
  Inputs: `Tracer`, `CorrelationID`, `System`, `Model`, `OperationName`.
  The `correlation_id` attribute links the span to the journal event (ADR-019).

- **`StartToolInvokeSpan`** / **`EndToolInvokeSpan`**: `genai.tool.invoke` span for each tool call.
  Inputs: `Tracer`, `CorrelationID`, `ToolName`, `OperationName`.

### 4. Journal Correlation

Both the OTel span and the `agent.llm.call.completed.v1` (or `agent.tool.invoked.v1`)
journal event carry the same `correlation_id`. This enables joint trace + event
queries in the observability backend.

### 5. Redaction Invariant

**Raw prompts, messages, and content NEVER appear in span attributes.**
The `Redactor` (ADR-066) produces a `RedactedSummary` (max 512 bytes) before
any content enters the span or journal. Negative TCK test:
`TestOTelGenAI_NoRawPromptAttrs` asserts that span attributes contain no key
matching `/^(prompt|messages|content)/i`.

## Consequences

**Positive:**
- OTel traces are standardized and queryable across all LLM adapters.
- Vendor SDK types stay in `adapters/`, satisfying ADR-045/047.
- Correlation between spans and journal events is guaranteed by shared `correlation_id`.
- Pinned version prevents silent breakage from SDK upgrades.

**Negative:**
- Any bump to a newer semconv requires a new ADR and a migration step.
- GenAI semconv is relatively new (v1.20.0 circa early 2025); future versions
  may rename attributes.

# ADR-083: AWS Managed Service Composition

**Status**: Accepted

**Date**: 2026-08-18

## Context

M8 (GA release) deploys GOLEM on AWS using managed services for durability and
scalability: Amazon RDS (journal), Amazon S3 (audit export), and AWS KMS (signing).
This ADR describes how the `aws_managed` profile selects and wires these adapters
and how the composition root handles credential resolution.

## Decision

We will implement AWS managed service composition with the following characteristics:

### 1. Profile: `aws_managed`

```yaml
version: 1
name: aws_managed
adapters:
  journal: rds
  transport: natsjs
  graph: memstore
  checkpoint: memstore
  registry: memstore
  search: memstore
  llm: openai-compatible
  policy: memstore
options:
  rds:
    connection_string: ${GOLEM_RDS_CONN}
    max_open_conns: 25
    max_idle_conns: 5
    conn_max_lifetime: 300
  s3:
    bucket: ${GOLEM_S3_BUCKET}
    region: ${AWS_DEFAULT_REGION}
    prefix: golem/
  kms:
    key_alias: alias/golem-export
    region: ${AWS_DEFAULT_REGION}
```

### 2. Adapter Selection

| Port | Adapter | AWS Service |
|------|---------|-------------|
| Journal | `adapters/journal/rds/` | Amazon RDS (PostgreSQL) |
| Audit Export | `adapters/storage/s3/` | Amazon S3 |
| Signing | `adapters/storage/kms/` | AWS KMS |
| Transport | `adapters/transport/natsjs/` | Amazon MSK (NATS) |

### 3. Credential Resolution

All AWS SDK clients use the default credential chain:
1. Environment variables (`AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY`)
2. Shared credentials file (`~/.aws/credentials`)
3. ECS container credentials
4. EC2 instance profile credentials (via IMDS)

No explicit credentials are stored in configuration. The composition root uses
`aws.Config.LoadDefaultConfig(ctx)` from AWS SDK v2.

### 4. RDS Journal Adapter

The RDS journal adapter implements `ports.JournalStore` using PostgreSQL:
- Table: `journal_events` with columns `(tenant_id, stream_id, version, event_type, payload, occurred_at)`
- Indexes on `(tenant_id, stream_id, version)` for efficient replay
- Optimistic concurrency via version checks on `AppendIf`
- Backup via `pg_dump` or RDS automated backups

### 5. S3 Audit Export Adapter

The S3 adapter (`adapters/storage/s3/`) uploads canonical export tars:
- Multipart upload with 5MB minimum part size (REQ-AUDIT-003)
- Exponential backoff: 3s, 6s, 12s retries
- SSE-KMS encryption using the CMK specified in profile options
- S3 Replication to secondary region for multi-AZ durability

### 6. KMS Signing Adapter

The KMS adapter (`adapters/storage/kms/`) signs manifest digests:
- Algorithm: `RSASSA_PKCS1_V15_SHA_256` (matching AC-14)
- Key resolution: `DescribeKey` resolves `alias/golem-export` to ARN
- No key material leaves AWS; signing happens server-side

## Consequences

- **Positive**: Managed services reduce operational overhead for database and storage.
- **Positive**: AWS SDK v2 default credential chain is secure and well-understood.
- **Positive**: RDS provides automated backups and point-in-time recovery.
- **Positive**: S3 provides 11 9s durability for audit exports.
- **Negative**: Vendor lock-in to AWS.
- **Negative**: Network latency to RDS/S3/KMS from compute tier.
- **Negative**: Requires IAM role configuration and VPC setup.

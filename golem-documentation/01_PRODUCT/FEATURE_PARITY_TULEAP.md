## Regla de reimplementación

Para cada capability: comportamiento observable → invariantes → bounded context → graph/events → API → acceptance tests → importer si procede.

## Spike

Antes de declarar paridad GA, inventario automático de la versión Tuleap de referencia y matriz feature-by-feature.

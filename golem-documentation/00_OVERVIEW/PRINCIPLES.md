# Principios de GOLEM

1. **Graph-native, no graph-as-dashboard.**
2. **Event history before mutable state.**
3. **Causality everywhere.**
4. **Evidence first.**
5. **Deterministic before agentic.**
6. **Proposal before privileged mutation.**
7. **Replaceability is tested.**
8. **Derived stores are disposable/rebuildable.**
9. **Cell-based SaaS.**
10. **Bounded contexts own meaning.**
11. **Stable contracts, evolvable internals.**
12. **Performance budgets are features.**
13. **Security is data.**
14. **Audit is a property of execution.**
15. **Simple deployment path first.**

# Glosario

| Término | Definición |
|---|---|
| Engineering Graph | Modelo graph-native de entidades y relaciones de ingeniería. |
| Graph Journal | Historial causal append-only. |
| Projection | Estado derivado: graph materializado, search, analytics, etc. |
| Behavior | Unidad reactiva activada por eventos/filtros/patterns. |
| Relation Behavior | Behavior cuya semántica pertenece a un edge. |
| Graph Lens | Vista acotada y read-only del grafo. |
| Change Proposal | Mutación propuesta con evidence y revision observada. |
| Execution Frame | Goal + scope + permisos + budgets + policies. |
| Scenario | Fork lógico para what-if, diff y promote. |
| Capability Pack | Extensión versionada de ontology/behaviors/policies/UI. |
| Port | Contrato del core hacia una capability externa. |
| Adapter | Implementación de un Port. |
| TCK | Suite común de conformidad de adapters. |
| Provider Profile | Selección de adapters para una cell/instalación. |
| Replaceability Level | R0–R5 de independencia real. |
| Cell | Unidad autosuficiente SaaS con tenants asignados. |
| Provenance | Evidencia verificable de cómo/dónde se produjo un artifact. |
| SBOM | Inventario estructurado de componentes. |
| VEX | Declaración de explotabilidad/estado de vulnerabilidad. |
